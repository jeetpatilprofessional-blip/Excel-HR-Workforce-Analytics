# HR Workforce Analytics Dashboard | Microsoft Excel

## Dashboard Preview

![Dashboard](HR%20Dashboard.png)

## Project Overview

This project focuses on analysing workforce data and developing an interactive HR Workforce Analytics Dashboard using Microsoft Excel.

The dashboard provides insights into employee demographics, department distribution, gender ratio, salary structure, employee performance, skills, work locations and employment status.

## Dataset Overview

- 100 employee records
- 21 data columns
- 5 departments
- 5 geographical regions
- 5 job roles
- 3 employment types

## Data Quality Note

The source dataset contains 100 employee records, including one missing Full Name and some missing optional fields such as insurance details, training programs and certifications.

The dashboard currently displays 99 total employees because its KPI counts nonblank Full Name entries. Employee ID can be used to count all 100 records.
